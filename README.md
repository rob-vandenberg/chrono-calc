# Chrono Calc

A desktop calculator for Linux that works like the classic calculator of the Windows 7 era: Standard, Scientific, Programmer and Statistics views, History, Digit grouping, and the side panels Unit conversion, Date calculation and Worksheets (mortgage, vehicle lease, fuel economy).

It looks at home on KDE Plasma and works on GNOME as well, on Debian, Ubuntu, Fedora and Red Hat family systems. In the application menu it is called **Calc**.

**Status:** in development. There is no release yet.

## Installing

When the first release is out, it comes as a package for your system:

1. Debian, Ubuntu and their family: download `chrono-calc_x.y.z.deb` from the Releases page and open it with your software installer (Discover on KDE, Software on GNOME).
2. Fedora, Red Hat and their family: download `chrono-calc_x.y.z.rpm` and open it the same way.

Calc then appears in your application menu.
